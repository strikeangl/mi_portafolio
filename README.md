# 🌌 Mi Portafolio Profesional - Gaming Edition

Proyecto personal desarrollado con **HTML5, CSS3 y JavaScript** (vanilla) diseñado para mostrar mi perfil académico, habilidades tecnológicas, proyectos y logros de manera organizada, estética y responsiva, con una temática visual de videojuegos estilo **neón gamer**.

---

## ✨ Características del Sitio

- 🎮 **Temática neón gamer** con colores vibrantes y efectos de brillo.
- ⚡ **Sistema de partículas interactivas** que reaccionan al cursor.
- ⌨️ **Efecto de escritura mecánica** (typewriter) en el hero.
- 🎭 **Scroll reveal** animado para tarjetas y secciones.
- 🌙 **Modo oscuro/claro** con persistencia en `localStorage`.
- ⬆️ **Botón de scroll al inicio** y **barra de progreso de scroll**.
- 🖱️ **Cursor personalizado** con efectos al pasar sobre elementos.
- 🔄 **Loader de página** animado al cargar el sitio.
- 📱 **Totalmente responsivo** (Media Queries).

## ⚙️ Arquitectura Técnica del Proyecto

### 🎨 Capa de Presentación (CSS)
- **`index.html` (bloque `<style>`)** → Hoja de estilos principal integrada. Gestiona la identidad visual gamer, la paleta cromática neón, las animaciones (`@keyframes`), el diseño responsivo (Media Queries) y el sistema de partículas.
- **`static/css/style.css`** → Hoja de estilos complementaria con estilos base, secciones de habilidades, certificaciones y ajustes de navegación.

### ⚡ Capa de Comportamiento (JavaScript)
- **`index.html` (bloque `<script>`)** → Script principal con la lógica de la aplicación: sistema de partículas interactivas, contador de estadísticas animado, scroll reveal, efecto typewriter, modo oscuro/claro, botón scroll-to-top, barra de progreso, cursor personalizado y loader de página.
- **`static/js/script.js`** → Script complementario con la lógica del formulario de contacto, animaciones de aparición de tarjetas y scroll suave.

### 🖼️ Capa de Recursos (Imágenes)
- Iconos de tecnologías, capturas de proyectos, foto de perfil y recursos institucionales (logos y banners de JMAKIT PRO).

## ⚙️ Uso con VS Code

No requiere instalación de dependencias, es un sitio **100% estático**.

### 1️⃣ Clona el repositorio

```
bash
git clone https://github.com/strikeangl/mi_portafolio.git
```

### 2️⃣ Entra al proyecto

```
bash
cd mi_portafolio
```

### 3️⃣ Abre el sitio

Puedes abrir directamente el archivo:

```
bash
index.html
```

o iniciar un servidor local:

```bash
python -m http.server 5500
```

Luego visita:

```
http://localhost:5500
```

También puedes utilizar la extensión **Live Server** de Visual Studio Code.
